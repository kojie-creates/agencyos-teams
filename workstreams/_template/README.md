# Workstream Template

Purpose:

```text
Provide a reusable packet for starting an AgencyOS Teams workstream.
```

Copy this folder and rename it:

```text
workstreams/{workstream-name}/
```

## Workstream Rule

Each workstream should have:

```text
clear owner
defined outcome
assigned Beings
assigned agencies
handoff path
evidence standard
closeout definition
learning destination
```

## Packet Files

```text
intake.md
plan.md
assigned-beings.md
assigned-agencies.md
handoffs.md
evidence.md
learning.md
closeout.md
deliverables/
```
