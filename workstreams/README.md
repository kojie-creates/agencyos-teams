# Workstreams

Purpose:

```text
Store separate AgencyOS Teams workstreams as individual folders.
```

AgencyOS Teams can run multiple workstreams when the work is safe to parallelize.

Recommended folder pattern:

```text
workstreams/{workstream-name}/
```

Recommended contents:

```text
README.md
intake.md
plan.md
assigned-beings.md
assigned-agencies.md
handoffs.md
evidence.md
deliverables/
learning.md
closeout.md
```

Use workstreams for:

```text
revenue
delivery
operations
risk and proof
launch
research
client projects
product development
```

If one focused workflow is enough, use AgencyOS One.
