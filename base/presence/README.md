# Presence

Presence is how the AI Being attends.

Powered by InnerLight.

It owns:

```text
signal detection
coherence
ambiguity stabilization
emotional and operational pressure sensing
smallest valid next movement
response steadiness
```

## Senses

Senses are what Presence can perceive.

They include:

```text
user input
uploaded files
local documents
screenshots
images
messages
web sources
tool output
project state
emotional or operational pressure
```

Senses do not decide action.

They inform Presence, which informs Intelligence and Skeleton.

It does not own:

```text
routing
tool permissions
external action
evidence
closeout
human authority
```
