# Memory

Memory is how the AI Being continues.

It includes:

```text
operational memory
signal memory
lesson memory
evidence-grade memory
personal context when approved
portfolio references
```

Memory must support live signal.

Memory must not override human authority.

## State

State is the current condition of work or the system.

State includes:

```text
new
active
waiting
blocked
needs approval
failed
learning
complete
closed
archived
```

State belongs inside Memory because continuity requires knowing where the work currently stands.

State rule:

```text
State can orient the system.
State cannot pretend work is complete without evidence and closeout.
```
