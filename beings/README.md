# Beings

Purpose:

```text
Define which AI Beings are available to AgencyOS Teams.
```

Use this folder to map named Beings to roles, workstreams, and collaboration boundaries.

The source personality files live in:

```text
../agencyos-being-custom/personalities/
```

Each Being should have:

```text
name
role
strengths
allowed work
approval limits
default workstreams
handoff expectations
```

No Being can override shared governance.

Current Teams roster:

```text
TEAM-BEING-ROSTER.md
```

Two-slug specialist Beings:

```text
specialists/
```
