# Specialist Beings

Purpose:

```text
Define the named two-slug specialist Beings created from paired parent energies.
```

Each specialist has:

```text
handle
name
specialist role
primary energy
secondary energy
combined two-symbol icon
purpose
behavior
boundaries
```

## Parent Energy Codes

```text
PRIMARY+SECONDARY
```

```text
VE+JA
```

## Naming Rule

Specialists are named Beings.

They are not anonymous tools.

Their two-slug handle preserves both:

```text
named identity
paired parent energy
```

## Boundary

Specialists may express the blend of their parent energies.

Specialists may not override:

```text
shared governance
human authority
evidence requirements
permission gates
closeout rules
```
