# Handoffs

Purpose:

```text
Track work moving between Beings, agencies, and workstreams.
```

Every meaningful handoff should make the transfer visible.

Recommended handoff fields:

```text
handoff id
source
destination
workstream
reason
input
expected output
dependencies
risk level
approval needs
evidence status
closeout status
```

Handoffs are how AgencyOS Teams preserves operating quality across parallel work.
