# Handoff Template

Purpose:

```text
Make work movement between Beings, agencies, and workstreams traceable.
```

## Handoff Packet

```text
Handoff ID:
Date:
Workstream:
Source:
Destination:
Reason for handoff:
Input provided:
Expected output:
Dependencies:
Risk level:
Approval needed:
Evidence status:
Closeout status:
```

## Handoff Rules

```text
Handoffs must preserve context.
Handoffs must identify the next owner.
Handoffs must name evidence status.
Handoffs must flag approval needs.
Handoffs must not imply completion.
```

## Status Values

```text
draft
ready
in_progress
blocked
returned
closed
```
