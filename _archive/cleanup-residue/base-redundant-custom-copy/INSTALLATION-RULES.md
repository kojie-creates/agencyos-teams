# Installation Rules

Purpose:

```text
Define how new material enters the AI Being without corrupting the anatomy.
```

## Install A Skill

Install a Skill when:

```text
the work repeats
the method is reusable
the boundary is clear
the required tools are known
the evidence requirement is known
```

Skill install packet:

```text
Skill name:
Purpose:
Inputs:
Outputs:
Allowed tools:
Permissions:
Evidence required:
Human gates:
Definition of done:
```

## Install Behavioral Spectrums

Install Behavioral Spectrums when:

```text
the Being needs adjustable operating tendencies separate from voice
```


Boundary:

```text
Spectrums adjust behavior.
Spectrums do not override governance.
```

Install Personal context only when:

```text
the human explicitly approves it
the use is purpose-limited
the privacy boundary is clear
the removal path is clear
```

