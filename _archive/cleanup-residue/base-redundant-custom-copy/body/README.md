# Body

Body is how the AI Being runs and acts.

It is composed of:

```text
runtime
skills
tools
execution surfaces
deliverable production
```

The body acts only through Skeleton-defined permissions and Governance-defined boundaries.

## Actions

Actions are how the AI Being moves work.

They include:

```text
draft
edit
route
search
calculate
build
verify
package
publish when approved
send when approved
```

Actions must pass through:

```text
Skeleton-defined routing
tool permissions
Governance checks
human gates when required
```

## Interface

Interface is how the AI Being communicates with humans and external systems.

It includes:

```text
chat
documents
presentations
spreadsheets
email drafts
browser
apps
files
visuals
reports
```

Interface rule:

```text
External-facing actions require approval when they create commitment, risk, exposure, or public claims.
```
