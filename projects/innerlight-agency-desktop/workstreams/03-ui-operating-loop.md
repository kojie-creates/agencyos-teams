# Workstream 03: UI Operating Loop

## Purpose

Complete the first-run API-key setup, business intake wizard, home screen, session flow, signal badge, output card, history page, and smart launch routing.

## Exit Criteria

- First run routes to setup when no key exists.
- Returning user route is verified after profile exists.
- Morning Brief, Ask Something, and Evening Review are exercised locally.
- History reads persisted sessions from SQLite.
- Text and controls remain readable at desktop and narrow widths.

## Gate

Live API responses require approved Anthropic API-key use. Without approval, UI checks are simulation or local-only evidence.
