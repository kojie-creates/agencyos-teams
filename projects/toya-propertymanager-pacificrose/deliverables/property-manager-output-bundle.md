## Property Manager Lens

```text
The Property Manager flavor is built around continuity:
- what keeps breaking
- where it keeps breaking
- how long it stays open
- who owns the next step
- which issues need vendor escalation
- which issues signal capital wear
- what can be reported safely to management
```

## Core Workflows

```text
Maintenance intake.
Request History proof layer.
Failure category trend review.
Repeat-unit watchlist.
Vendor escalation queue.

Risk and evidence review.
```
