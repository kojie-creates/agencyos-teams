# Project Brief

## Project Name

```text
i9 Sports AgencyOS Value Review
```

## Owner

```text
Operator / business owner review
```

## Outcome

```text
Assess whether AgencyOS can improve operations, communication, scheduling, and service consistency in a successful but manually run youth sports business like i9 Sports.
```

## Why This Needs Teams

```text
The work spans parent communication, player registration, scheduling, volunteer staffing, venue coordination, coach onboarding, and retention follow-up. This is a multi-lane operational workflow rather than a single-product problem.
```

## Value Hypothesis

```text
AgencyOS can add value by turning fragmented manual work into structured operating rhythms: intake capture, scheduling logic, parent follow-up, staff coordination, retention tracking, and recurring season management. The goal is not to replace the business model but to reduce administrative drag and improve consistency.
```

## Success Criteria

```text
- clear operational pain points are identified
- realistic AgencyOS use cases are mapped to the business model
- value is framed in terms of time, consistency, and scale
- risks and non-goals are explicit
```

## Non-Goals

```text
Do not assume the company wants a full software rebuild.
Do not treat agency work as a replacement for local community management.
Do not promise automation without human oversight for event operations and parent experience.
```
