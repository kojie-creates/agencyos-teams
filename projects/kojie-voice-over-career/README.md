# Project Template

Purpose:

```text
Provide a reusable packet for starting a complex AgencyOS Teams project.
```

Copy this folder and rename it:

```text
projects/{project-name}/
```

## Project Rule

Each project should have:

```text
clear project owner
defined project outcome
assigned Beings
assigned agencies
workstreams
handoff path
project governance notes
evidence standard
closeout definition
learning destination
```

## Packet Files

```text
intake.md
project-brief.md
plan.md
assigned-beings.md
assigned-agencies.md
governance-notes.md
handoffs.md
learning.md
closeout.md
workstreams/
deliverables/
evidence/
```
