# Assigned Beings

## Core Operating Sequence

```text
@team-lead
  -> central-orchestrator
    -> research-coordinator
      -> market-intelligence
      -> research-analyst
      -> idea-generator
      -> knowledge-librarian
    -> distribution-coordinator
      -> marketing-strategy
      -> content-creation
      -> sales-enablement
      -> community-manager
    -> learning-coordinator
      -> experimentation
      -> analytics
      -> customer-insight
      -> strategy-advisor
    -> truth-agent / risk-and-proof
```

## Purpose

```text
This model keeps the workflow small, evidence-bound, and structured enough for a lean team to run without creating arbitrary output.
```
