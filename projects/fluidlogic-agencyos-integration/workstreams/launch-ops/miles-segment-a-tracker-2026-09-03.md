# Miles — Segment A private outreach tracker

**Date:** 2026-09-03  
**Mode:** private ops. Not a public launch. No ads, no site, no LinkedIn blast.  
**Cap:** 10–20 riders in. Outreach list can be larger; **do not onboard past 20.**  
**Offer:** Juan circles loan / trial / purchase on the one-pager before first send.

Companion file (open in Excel / Sheets):  
`miles-segment-a-tracker-2026-09-03.csv`

---

## How to use

1. Put names Juan already has (two-wheel heat). No purchased lists.  
2. Send **invite + FAQ** only. Log the date.  
3. Day 4: one follow-up from Theo's kit. Then stop or book a 15-min call.  
4. Fill the row in their words. If they ask for a performance claim, log it and do **not** promise it.  
5. Status `in` only if: helmet + bars, water-only yes, will ride heat, weekly check-in yes.  
6. When `in` count hits 20, freeze recruiting. Waitlist = `later`.

---

## Status values

| Status | Meaning |
| --- | --- |
| not_contacted | on the list, nothing sent |
| outreached | invite sent |
| follow_up | day-4 ping sent |
| replied | they answered |
| call_booked | 15-min on calendar |
| in | in the 10–20 block |
| excluded | wrong kit / wants mix / no-bar sport |
| declined | fit but no |
| later | waitlist or timing |

---

## Weekly (private)

**Monday:** who to text (max 10 new).  
**Wednesday:** follow-ups + objections in their words.  
**Friday:** count `in` / `excluded` / `declined`. If a claim leaked public, Vera review before anything else.

**Do not:** paid ads, blast, landing page, "announce the elite athlete launch."

---

## Escalation

| Signal | Action |
| --- | --- |
| They want mix in the pack | `excluded` — do not argue |
| They want NASCAR-win proof | use Theo line; log; do not send VMR as GPR50 |
| They ask to post a win claim | no; note in `claims_they_asked` |
| 20 `in` | stop recruiting |
| <5 `in` after two weeks of real names | revise outreach, not the sport |
| Weight/water-only killing the list | **revise or stop** per pilot brief — do not pivot to runners |

---

## Continue / revise / stop (from first replies, not from vibes)

- **Continue** this segment if people understand "button on the bar" fast and ask about the block.  
- **Revise** if they want it but fail install / water / weight.  
- **Stop** if the kit is a no for two-wheel heat. New sport = new brief.
