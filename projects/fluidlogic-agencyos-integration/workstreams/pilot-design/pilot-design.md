# Pilot Design Workstream

## Goal

```text
Design a first commercial test for a narrow athlete segment with clear success metrics and minimal operational burden.
```

## Pilot Design Structure

```text
- choose a sharp wedge
- define a 90-day test scope
- select a buyer and an influencer
- set success metrics before launch
- document proof requirements and feedback loop
```

## Recommended pilot wedge

```text
High-heat endurance or high-load performance athletes with a coach or performance team involved.
```

## Example Success Metrics

```text
- pilot conversion rate
- athlete or coach willingness to continue
- number of qualified conversations
- signal quality from referrals or team introductions
- clarity of proof requirements for scaling
```

## Deliverable

```text
A pilot brief that is narrow enough to execute, measurable enough to learn from, and aligned to the premium athlete brand. The recommended pilot design emphasizes a small, focused set of athlete conversations over broad market expansion.
```
