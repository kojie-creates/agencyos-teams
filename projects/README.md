# Projects

Purpose:

```text
Store multiple complex AgencyOS Teams projects as separate folders.
```

AgencyOS Teams can support many projects.

Each project can contain:

```text
multiple workstreams
multiple Beings
multiple agencies
project-level governance notes
handoff records
evidence
deliverables
learning
closeout
```

## Folder Pattern

Create one folder per project:

```text
projects/{project-name}/
```

Use the reusable template:

```text
projects/_template/
```

## Relationship To Workstreams

Projects are the container.

Workstreams are the lanes inside a project.

```text
project = full complex effort
workstream = bounded lane of work inside the project
```

Example:

```text
projects/fluidlogic-elite-athlete-transition/
  workstreams/research/
  workstreams/positioning/
  workstreams/sales-enablement/
  workstreams/pilot-design/
  workstreams/learning-loop/
```

Current project packets:

```text
projects/fluidlogic-agencyos-integration/
projects/i9sports-agencyos-value/
```

## Project Rule

Projects may run multiple workstreams when safe.

Shared governance still applies across all project lanes.

The human remains final authority.
