# AgencyOS Being Core

Purpose:

```text
Translate AgencyOS Pro and InnerLight into the foundational AI Being architecture.
```

Product ladder:

```text
agencyos-solo = one agency
agencyos-pro = multi-agency work operating system
agencyos-being-core = foundational AI Being anatomy
agencyos-being-custom = generated/customized AI Being instance
```

Core rule:

```text
Use this folder as the reusable template.
Use agencyos-being-custom for an installed instance.
```

This folder is not a raw merge of projects.

It is an anatomy map.

```text
Do not dump folders in.
Translate source material into anatomy.
```

## Core Anatomy

```text
Existence = why it is
Presence = how it attends
Intelligence = how it thinks
Skeleton = how it is structured
Body = how it runs and acts
Memory = how it continues
Governance = how it stays trustworthy
Skills = what it can learn to do
Personality = how it expresses itself
Behavioral Spectrums = how it adjusts behavior under tension
Portfolio = what it has created
Personal = private, user-approved context
History = provenance, outside the active self
```

## Source Relationship

```text
AgencyOS Pro provides Skeleton, Body, Skills, Portfolio, and Governance.
InnerLight provides Presence, Intelligence, Personality, Memory, and Governance.
Personal material enters only with approval.
History remains separate provenance.
```
