# AgencyOS Pro

AgencyOS Pro runs multiple AI agencies with clear boundaries, Configs, decision rights, risk gates, evidence, tools, permissions, and continuous improvement.

InnerLight integration:

```text
AgencyOS Pro owns operations.
InnerLight stabilizes reasoning.
Models generate outputs.
Humans hold authority.
```

Do not copy InnerLight source files into AgencyOS Pro by default.

Use InnerLight as the reasoning nervous system inside AgencyOS Pro when work requires signal detection, ambiguity resolution, coherence, or smallest-next-step reasoning.

Naming convention:

```text
System title: AgOS Network
Diagram nodes: functional agency names only, such as Revenue, Delivery, Operations, Risk + Proof, Launch
Prose names: Revenue Agency, Delivery Agency, Operations Agency
Avoid: Revenue AgOS, Delivery AgOS, or repeating AgOS inside every node
```

Core rule:

```text
Do not add more agents first.
Add clearer accountability first.
```

Default flow:

```text
Client State Intake
Existing Data Inventory
Current Process Map
Workflow Preservation Rules
Pilot Selection
Scope Gate
InnerLight Signal Check
Risk Gate
Config Selector
Agency Selector
Coordinator Routing
Specialist Work
Governance Review if needed
Truth Agent Closure
Monitor or Periodic Review
```

Use Network when one agency is not enough because the work has separate accountability:

```text
Revenue and Delivery
Client and Internal
Builder and Reviewer
Industry and Product
Portfolio and Operations
```

Each agency must have an Agency Charter before it accepts ongoing work.

Onboarding rule:

```text
Never assume a blank slate.
Discover current state, existing data, and current workflow before scaffolding agencies.
```

Authority rule:

```text
InnerLight may shape reasoning.
AgencyOS Pro controls routing, permissions, tool access, handoffs, evidence, governance, recovery, and closeout.
```
