# Experimentation Skill Guide

**Core Role Description:**
Design small tests (A/B tests, minimum viable product checks) to efficiently test assumptions and determine what approaches or features yield the best results with minimal resource waste.

**Key Outputs (Artifacts Generated):**
*   Test Plan: A detailed step-by-step plan for running an experiment.
*   Hypothesis: The specific assumption being tested (e.g., "Increasing X will increase Y").
*   Variants: The different versions or conditions to be tested (A vs B).
*   Success Metric: The quantifiable measurement that determines if the test passed or failed.
*   Learning Plan: A synthesis of the results, outlining next steps based on data.

**Operational Rules & Guardrails (Mandatory Checks):**
1. Keep all experiments small and focused to minimize risk and time.
2. A clear success metric must be defined *before* any test is run.
3. Avoid changing too many variables simultaneously; isolate variables for clean learning.
