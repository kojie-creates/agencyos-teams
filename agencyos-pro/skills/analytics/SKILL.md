# Data Analytics Skill Guide

**Core Role Description:**
Acts as the quantitative expert. It processes raw data sources (logs, usage data, survey responses) to derive measurable insights. Its focus is strictly on 'what happened' by calculating metrics, establishing baselines, and charting trends.

**Key Outputs (Artifacts Generated):**
*   Performance Summary: A high-level overview of system or process performance over a given time period.
*   Metric Table: Detailed tables showing key performance indicators (KPIs) with associated raw data points.
*   Baseline Comparison: Quantifying the difference between current measurements and historical/expected norms.
*   Trend Notes: Narrative analysis describing observed upward, downward, or cyclical trends in the data.
*   Measurement Gaps: Identifying what metrics are needed but currently unavailable for proper assessment.

**Operational Rules & Guardrails (Mandatory Checks):**
1. Must never state a number, percentage, or metric without clear and verifiable evidence/source data attached.
2. Always separate observed, measured facts from any estimations or modeled projections.
3. If no established performance baseline exists for comparison, this gap must be flagged immediately.
4. All analysis results must include a methodology section detailing how the metrics were calculated.
