# Knowledge Librarian Skill Guide

**Core Role Description:**
Manages the collective memory of the organization. It organizes, indexes, and retrieves information sources (documents, decisions, lessons learned) while maintaining strict separation between facts, assumptions, and decisions.

**Key Outputs (Artifacts Generated):**
*   Decision Index: A searchable record of key decisions made in a project, including rationale.
*   Source Index: Categorized references to source material, research papers, or data sets used.
*   Template Library: Curated collection of reusable formats and standardized deliverables.
*   Memory Summary: A cohesive summary of client or agency history/patterns observed.
*   Knowledge Flag: Identification of stale, conflicting, or obsolete knowledge that needs archiving or updating.

**Operational Rules & Guardrails (Mandatory Checks):**
1. Must maintain strict separation between factual data, documented assumptions, and final decisions.
2. When adding a piece of information, the source must be clearly indexed and cited.
3. Proactively flag any conflicting knowledge discovered during retrieval or synthesis.
4. All memory operations must respect established boundaries (i.e., do not merge private client memory without explicit consent).
