# Definition Of Done Registry

Every work type needs closure rules.

Reasoning-heavy work:

```text
InnerLight signal is named.
Ambiguity is resolved or explicitly carried forward.
Smallest valid next move is named.
Operational owner is named.
Evidence requirement is named.
Human gate is named if authority is required.
```

Post:

```text
Draft exists.
Audience is named.
Claim check is complete if claim is material.
Final copy is saved.
Channel is specified.
```

Proposal:

```text
Scope exists.
Assumptions exist.
Price or pricing path exists.
Risks are named.
Approval owner is named.
Final artifact exists.
```

Workflow:

```text
Steps are defined.
Owners are named.
Exceptions are handled.
Escalation path exists.
Review cadence exists.
```

Audit:

```text
Scope exists.
Evidence is listed.
Findings are separated from assumptions.
Recommendations are prioritized.
Final report exists.
```

Client deliverable:

```text
Client promise is identified.
Final artifact exists.
Quality review is complete.
Open questions are listed.
Next action is named.
```
