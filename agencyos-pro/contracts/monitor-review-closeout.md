# Monitor Or Review Closeout

Every closed task gets one follow-up label.

```text
No follow-up needed
Monitor
Periodic review
Convert to template
Archive
```

Closeout rule:

```text
AgencyOS Pro owns closeout.
InnerLight may support coherence checks, but cannot mark work complete.
Truth Agent verifies evidence before closure.
Human owner approves when authority is required.
```

Monitor when work keeps running:

```text
workflow
funnel
client reporting
vendor process
invoice review
support intake
```

Periodic review when item is stable but important:

```text
template
policy
pricing page
agent instruction
checklist
approved language
```
