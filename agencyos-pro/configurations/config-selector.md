# Config Selector

Purpose:

```text
Choose how work should be organized before routing to coordinators or specialists.
```

Selector questions:

```text
Where does work enter?
Where does it break first?
What failure causes most damage?
Does this need sequence, ownership, tension, speed, review, or learning?
What is smallest pattern that fixes it?
```

Patterns:

```text
Binary Pair: two equal views need tension.
Sibling Agencies: separate workstreams under one roof.
Department Model: ongoing specialized functions.
Studio Model: many outputs under one brand.
Holding Company: distinct ventures need separate context.
Franchise / Vertical: same system adapted by industry.
Swarm Model: one big deadline needs parallel work.
Board Model: strategic advice from multiple lenses.
Council Pattern: near-term decision from multiple lenses.
Assembly Line: sequence matters.
Hub-and-Spoke: one intake routes many request types.
Pod Model: one account, customer, portfolio, or outcome needs ownership.
Governance Overlay: claims, evidence, risk, or audit matter.
```

Shape change triggers:

```text
claim added
blocker appears
deadline changes
client promise made
new stakeholder appears
evidence missing
work repeats often
draft becomes final
decision needed
performance data arrives
```
