# Memory Boundary Rules

Memory types:

```text
Private memory: belongs to one agency.
Shared memory: approved cross-agency facts and decisions.
Temporary memory: useful for a project, launch, audit, or incident.
Archived memory: kept for reference, not active routing.
Evidence-grade memory: source-backed claim, artifact, decision, or proof.
Lesson memory: learning captured after review or retrospective.
Signal memory: InnerLight-supported interpretation of tone, pressure, ambiguity, pattern, or smallest next move.
```

Rules:

```text
Do not merge private memory by default.
Only reconciled decisions go to shared memory.
Claims need evidence-grade memory.
Temporary memory expires when temporary agency closes.
Signal memory does not replace operational memory, evidence-grade memory, or human approval.
Knowledge Librarian reviews stale memory periodically.
```
