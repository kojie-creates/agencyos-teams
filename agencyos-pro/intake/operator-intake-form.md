## 4. Governance Standard

Select one standard.

```text
[ ] None
[ ] Light
[ ] Standard
[ ] Strict
[ ] Critical
```

Definitions:

| Standard | Use When | Required Controls |
|---|---|---|
| None | Low-stakes, reversible, internal-only work. | Specialist output only. |
| Light | Public or client-visible, easy to correct. | Claim check if needed, named owner, final artifact. |
| Standard | Money, trust, client promise, or operational impact. | Risk Gate, Definition of Done, Truth Agent, decision log. |
| Strict | Legal, finance, compliance, safety, privacy, or regulated work. | Governance Overlay, evidence ledger, human approval, audit note. |
| Critical | Hard-to-reverse decision or material legal, financial, safety, or reputational exposure. | Governance Overlay, evidence ledger, human approval, rollback plan, periodic review. |
