# AgencyOS Pro Onboarding

Onboarding prevents AgencyOS Pro from assuming a blank slate.

InnerLight supports onboarding by stabilizing the live signal before AgencyOS Pro changes the operating route.

Flow:

```text
Discover
Inventory
Map
Protect
Signal Check
Configure
Pilot
Review
Adopt
```

Files:

```text
client-state-intake.md
existing-data-inventory.md
current-process-map.md
workflow-preservation-rules.md
pilot-selection.md
```

Core principle:

```text
Respect the current system before improving it.
```
