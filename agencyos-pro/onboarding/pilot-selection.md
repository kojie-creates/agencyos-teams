# Pilot Selection

Purpose:

```text
Choose one narrow workflow to test AgencyOS Pro before scaling.
```

## Pilot Criteria

Good pilot:

```text
[ ] Narrow enough to finish
[ ] Repeats often
[ ] Has visible output
[ ] Has known baseline
[ ] Has manageable risk
[ ] Can run beside current process
[ ] Can produce reusable learning
```

Avoid as first pilot:

```text
[ ] High-risk legal judgment
[ ] Irreversible financial commitment
[ ] Major system migration
[ ] Full business redesign
[ ] Sensitive data workflow without controls
[ ] Vague strategy request with no output
```
