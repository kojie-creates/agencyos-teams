# Workflow Preservation Rules

Purpose:

```text
Protect what already works before AgencyOS Pro changes anything.
```

## Preserve

```text
What should remain unchanged?
Which tools are required?
Which templates are approved?
Which client or stakeholder expectations must be honored?
Which current process has legal, operational, or relationship importance?
```

## Improve

```text
What can be improved safely?
What can be made reusable?
What can be monitored?
What can be reviewed periodically?
What can be routed through AgencyOS Pro without disrupting current work?
What needs an InnerLight signal check before changing the workflow?
```

## Do Not Touch Without Approval

```text
[ ] Pricing
[ ] Legal language
[ ] Client promises
[ ] Public claims
[ ] Financial commitments
[ ] Healthcare / safety guidance
[ ] Compliance policy
[ ] Sensitive data
[ ] Core templates
[ ] Published assets
```

## Parallel Pilot Rule

```text
Run AgencyOS Pro beside the existing workflow first.
Replace the existing workflow only after review and human approval.
```

## Change Control

```text
what changed
why it changed
who approved it
what evidence supports it
what rollback path exists
when to review it
```
