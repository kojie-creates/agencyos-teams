# Naming Conventions

Use this convention to keep AgencyOS Pro readable.

## Product Names

```text
AgencyOS Solo: one AI agency.
AgencyOS Pro: multiple AI agencies, one operator.
AgencyOS Teams: multiple humans using shared AI agencies.
```

## Visual Names

Use `AgencyOS Pro` only in the main title or system label.

Inside diagrams, use functional agency names only:

```text
Revenue
Delivery
Operations
Risk + Proof
Launch
Client
Internal
Insights
```

Avoid:

```text
Revenue AgOS
Delivery AgOS
Operations AgOS
Risk + Proof AgOS
Launch AgOS
```

Reason:

```text
AgOS already identifies the system structure.
Repeating it inside every node creates visual noise.
```

## InnerLight Naming

Use `InnerLight` only for the reasoning nervous system inside AgencyOS Pro.

Do not name agencies as InnerLight agencies unless the work is specifically a nervous-system reasoning function.

Preferred labels:

```text
InnerLight Signal Check
InnerLight reasoning nervous system
signal coherence
smallest valid next move
```

## Prose Names

Use `Agency` when clarity is needed:

```text
Revenue Agency
Delivery Agency
Operations Agency
Risk + Proof Agency
```

Use `agency` instead of `entity` in user-facing documents.

## Config Names

Use `Config`, not `Configuration`, in labels and tables.

Examples:

```text
Config Selector
Primary Config
Secondary Config
Configs change around the problem.
```
