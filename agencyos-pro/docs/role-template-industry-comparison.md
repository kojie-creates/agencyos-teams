## Interpretation

The InnerLight role templates are profession support roles.

They stabilize the human loop:

```text
Human -> Artifact -> Audience
```

AgencyOS Pro adds operating infrastructure around that loop:

```text
Intake -> Agencies -> Configs -> Specialists -> Governance -> Truth -> Memory -> Improvement
```
