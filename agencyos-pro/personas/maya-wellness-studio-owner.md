# Persona Profile: Maya, Wellness Studio Owner

Use case:

```text
AgencyOS Pro onboarding example for an existing business with real data, existing workflows, and operational habits already in place.
```

## Persona

Name:

```text
Maya Thompson
```

Role:

```text
Owner-operator of a small wellness studio offering yoga, breathwork, mobility classes, and private sessions.
```

Business stage:

```text
Existing business, informal process.
```

Current situation:

```text
Maya has steady clients, a small instructor network, a class schedule, social media presence, and recurring workshops. The business works, but too much lives in her head.
```

## What Already Exists

Data and artifacts:

```text
Google Calendar class schedule
Stripe payment history
Mailchimp list
Instagram posts
Google Sheets attendance tracker
waiver PDFs
workshop templates
client intake forms
instructor notes
private client follow-up notes
```

Current workflows:

```text
Classes are scheduled manually.
Attendance is updated in a sheet.
Workshop posts are written the week before launch.
Private client follow-ups happen from memory.
Instructor substitutions happen by text.
Waivers are stored but not reviewed regularly.
```

What works:

```text
Clients trust Maya.
The class schedule is consistent.
Workshops sell when promoted early.
Instructor relationships are strong.
```

What hurts:

```text
Follow-ups are inconsistent.
Workshop promotion starts too late.
Attendance trends are not reviewed.
Client notes are scattered.
Health and wellness claims need caution.
```

## Onboarding Result

Recommended agencies:

| Agency | Config | Owns |
|---|---|---|
| Client Care | Pod | private clients, follow-ups, intake notes |
| Class Operations | Assembly Line | schedule, attendance, instructor handoffs |
| Workshop Growth | Studio | workshop campaigns, posts, email copy |
| Risk + Proof | Governance | wellness claims, waiver review, sensitive notes |
| Insights | Continuous Improvement | attendance trends, workshop performance, retention signals |

Governance standard:

```text
Strict for health claims and private client notes.
Standard for workshop promotion and class operations.
```

Memory boundaries:

```text
Private memory:
- private client notes
- health-sensitive intake details

Shared memory:
- class schedule
- workshop calendar
- approved public language
- attendance trends

Evidence-grade memory:
- waivers
- approved claims
- payment records
- published workshop pages
```

## Pilot Selection

Pilot:

```text
Launch one weekend breathwork workshop.
```

Why this pilot:

```text
It repeats often, has a visible output, uses existing data, carries moderate claim risk, and can run beside Maya's current process.
```

Current baseline:

```text
Maya usually promotes workshops late and writes posts from scratch each time.
```

AgencyOS Pro pilot output:

```text
workshop campaign plan
3 Instagram post drafts
1 email announcement
1 instructor handoff note
1 claim-safe workshop description
1 registration follow-up template
1 post-workshop review form
```

## Example Starting Prompt

```text
@operator Onboard my wellness studio without assuming a blank slate. I already have a calendar, attendance sheet, Mailchimp list, Stripe records, client notes, and workshop templates. Help me run one breathwork workshop pilot while preserving what already works.
```

## How The Setup Protects Existing Workflow

Preserve:

```text
Google Calendar remains source for class schedule.
Mailchimp remains email tool.
Stripe remains payment source.
Existing waiver PDFs remain evidence-grade records.
```

Improve:

```text
Workshop promotion starts earlier.
Client follow-up gets a weekly review.
Claims are checked before publication.
Attendance trends feed monthly planning.
```

Do not touch without approval:

```text
pricing
waiver language
health claims
private client notes
published workshop copy
```

## Why This Persona Works

This scenario shows AgencyOS Pro entering an existing business carefully.

It does not replace Maya's workflow immediately.

It first:

```text
discovers current state
inventories existing data
maps current workflow
protects sensitive processes
selects one pilot
configures agencies around reality
reviews results before adoption
```
