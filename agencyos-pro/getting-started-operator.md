# Getting Started With AgencyOS Pro

1. Capture client state.
2. Inventory existing data.
3. Map current process.
4. Protect workflows that should not be disturbed.
5. Select one pilot.
6. Run an InnerLight signal check for ambiguity, pressure, contradictions, and smallest valid next move.
7. Define each AI agency.
8. Write an agency charter for each one.
9. Choose a primary Config for each agency.
10. Set decision rights, tool access, permissions, and memory boundaries.
11. Route new work through Scope Gate, InnerLight Signal Check, Risk Gate, and Config Selector.
12. Automate known handoffs unless a human gate is reached.
13. Close work only after Truth Agent verification.
14. Label closed work as monitor, periodic review, template, archive, or no follow-up.
