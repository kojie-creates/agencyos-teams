# AgencyOS Teams Marketing Sheet

## Product Equation

```text
AgencyOS Teams = AI Beings + AgencyOS Pro
```

## Core Positioning

AgencyOS Teams gives a person or organization a coordinated team of trusted AI partners for work that needs routing, parallel execution, governance, handoffs, and learning.

Most AI tools help with output.

AgencyOS Teams helps with operating quality across multiple lanes:

```text
beings
workstreams
routing
handoffs
governance
evidence
learning
```

## Buyer-Facing Message

AgencyOS Teams is for work that is too complex for one assistant.

It combines multiple AI Beings with AgencyOS Pro, so each workstream can move through the right agencies while shared governance keeps the system accountable.

The user keeps authority.

The team handles coordination.

## What It Does

| Layer | Buyer Meaning |
| --- | --- |
| **AI Beings** | Named collaborators with distinct roles, personalities, and strengths. |
| **AgencyOS Pro** | The network operating layer that routes work across agencies. |
| **Workstreams** | Separate lanes for revenue, delivery, operations, risk, launch, and learning. |
| **Handoffs** | Traceable movement of work between Beings, agencies, and workstreams. |
| **Governance** | Shared trust and approval rules that apply across the whole team. |
| **Learning** | Patterns from one lane improve the next lane. |

## Best Fit

AgencyOS Teams is best when the work has:

```text
multiple workstreams
multiple AI collaborators
parallel execution
cross-functional handoffs
shared governance
one clear human authority
```

## Sales Language

AgencyOS Teams is not another chatbot.

It is a coordinated operating surface for bigger work.

Instead of asking one model to do everything, AgencyOS Teams routes the request through the right Beings, agencies, workstreams, and governance gates.

That means complex work can move without losing the thread.
