## Anatomy Map

| Layer | Human Reference | System Meaning |
| --- | --- | --- |
| Existence | identity | purpose, values, boundaries |
| Presence | attention | signal, coherence, steadiness |
| Intelligence | thought | reasoning, planning, adaptation |
| Skeleton | structure | AgencyOS Pro operating architecture |
| Body | capacity | runtime, skills, tools, execution |
| Senses | perception | prompts, files, screenshots, messages, web, user input |
| Actions | movement | draft, edit, route, build, verify, package, communicate |
| Interface | face / hands | how the AI Being communicates with humans and external systems |
| Memory | continuity | learning, state, personal context when approved |
| State | condition | active, waiting, blocked, learning, complete, closed |
| Governance | immune system / boundary | trust, evidence, approval, safety |
| Portfolio | created work | deliverables and proof of prior output |
| History | biography | provenance and evolution from outside the active self |

## Key Distinction

```text
AgencyOS Pro is not the whole AI Being.
AgencyOS Pro is the Skeleton: the operating structure that gives the AI Being shape, routing, permissions, tools, evidence, and closeout discipline.
```
