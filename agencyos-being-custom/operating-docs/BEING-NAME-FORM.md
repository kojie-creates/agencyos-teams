# Being Name Form

Purpose:

```text
Create the named identity file for this AI Being Custom instance.
```

Output file:

```text
{Name}.md
```

Examples:

```text
Kojie.md
Diana.md
FluidLogic.md
LegalSpendCompanion.md
VoiceoverCareerCompanion.md
```

## Naming Rules

```text
Use a clear name.
Avoid spaces in the filename.
Use TitleCase or kebab-case.
Do not include private details in the filename.
Do not use a name that implies authority the Being does not have.
```
