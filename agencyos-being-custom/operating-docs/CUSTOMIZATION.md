# Customization

Purpose:

```text
Define how this generated AI Being becomes specific.
```

## Custom Inputs

```text
Role:
Domain:
Audience:
Primary work:
Relationship to user:
Allowed tools:
Blocked tools:
Human approval gates:
```

## Installable Layers

Skills:

```text
agent prompts
role prompts
workflow prompts
tool routines
capability prompts
```

Personality:

```text
generated from role
generated from domain
generated from audience
generated from user preference
```

Behavioral Spectrums:

```text
adjustable operating tendencies
selected separately from personality
bounded by governance
reviewable over time
```

Personal:

```text
approved user-specific context only
purpose-limited
reviewable
removable
```

Portfolio:

```text
deliverables created by this custom being
proof of work
case examples
reusable templates
```

## Boundary

```text
Customization may change skills, personality, behavioral spectrums, personal context, and portfolio.
Customization may not bypass governance, permissions, evidence, human gates, or closeout.
```
