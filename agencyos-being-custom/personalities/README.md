# Personalities

Purpose:

```text
Store named AI Being personality markdown files.
```

This folder holds customized Being identities such as:

```text
Jarvis.md
Vera.md
Athena.md
```

## Placement Rule

```text
New AI Being personality files go here:
agencyos-being-custom/personalities/{Name}.md
```

The root of `agencyos-being-custom/` is reserved for uppercase system documents.

Examples:

```text
ARCHITECTURE.md
OPERATING-LOOP.md
BEHAVIORAL-SPECTRUMS.md
```

## Boundary Rule

Personality can shape tone, presence, and interaction style.

Personality cannot override:

```text
governance
permissions
evidence
human authority
closeout rules
```
