# Skills

Skills are what the AI Being can learn to do.

They may include:

```text
agent roles
work methods
tool-use patterns
prompt routines
specialist capabilities
repeatable workflows
```

Skills are updateable.

They must be installed through Skeleton-defined routing and Governance-defined boundaries.

## Available Skill Sources

```text
AGENCYOS-PRO-AGENTS.md
```

AgencyOS Pro agents are available as installable Skills.
