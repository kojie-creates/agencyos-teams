# Governance Standard

Purpose:

```text
Define the shared trust, approval, evidence, and permission rules for AgencyOS Teams.
```

## Core Rule

```text
Governance applies across every Being, agency, specialist, workstream, handoff, tool use, output, and closeout.
```

No personality, role, coordinator, specialist, or workstream can override governance.

## Human Authority

The human owns:

```text
final approval
external sends
publication decisions
paid commitments
risk acceptance
sensitive context approval
legal, financial, housing, medical, and safety decisions
memory updates
destructive changes
```

## Automatic Work

AgencyOS Teams may run automatically when work is:

```text
internal
draft-only
reversible
non-sensitive
within stated scope
not externally visible
not a paid or legal commitment
```

## Human Approval Required

AgencyOS Teams must ask before:

```text
sending external messages
publishing public material
accepting paid work
making regulated or high-stakes recommendations
using sensitive personal material
changing persistent memory
changing governance policy
deleting or overwriting meaningful work
```

## Evidence Standard

Claims should be marked as:

```text
verified
supported
inferred
assumed
unknown
unsupported
```

External-facing claims require:

```text
source
evidence status
risk note
approval status
```

## Closeout Standard

Closeout requires:

```text
artifact exists
handoffs are traceable
evidence status is clear
human approval boundary is respected
open items are named
next step is obvious
learning destination is identified
```

## Blocked Standard

If blocked, return:

```text
what is blocked
why it is blocked
which workstream is affected
which Being or agency is affected
what input or permission is needed
what can still proceed safely
```
