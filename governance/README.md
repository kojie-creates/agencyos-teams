# Governance

Purpose:

```text
Define shared rules for trust, permission, risk, evidence, and approval.
```

Governance applies across:

```text
Beings
AgencyOS Pro agencies
workstreams
handoffs
tool use
external-facing actions
closeout
```

Governance should answer:

```text
what can run automatically
what requires review
what requires approval
what evidence is required
what claims are allowed
what actions are blocked
```

No Being, agency, workstream, or personality can override governance.
